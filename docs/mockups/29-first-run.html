D and E. Connecting a real tenant

The review stage says plainly that permissions are delegated. The connected stage reports what was added to the tenant, using Entra's name for it, so an admin can find it under Enterprise applications.

Review the read access OpenAdminOS requests before Microsoft sign-in.

Delegated permissions. OpenAdminOS can only read what both these permissions and your own admin role allow. Intune RBAC roles and scope tags still apply.
No client secret is used. OpenAdminOS signs in as a public client (Authorization Code with PKCE), so there is no secret to store on this device.
