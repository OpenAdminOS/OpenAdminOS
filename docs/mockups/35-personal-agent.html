An agent of your own: a name, a way of answering, and only the access you give it.

The personal agent is the one agent that answers in Chat and voice. The admin names it, sets how it answers, grants what it may reach, keeps a library of skills for it and approves everything it learns. Nothing here can grant a change to a tenant: changes still go through agents and diff confirmation. Type a name in A; every mention on this page follows. Check the frames at 1280 and 900 px, in both themes.

C. The skills library

A skill is a named procedure Nova loads when a question matches its description. Each one is a SKILL.md file in the open format, so it can be imported from and exported to any tool that reads that format. The library lists skills with their version and scope, and the detail shows the procedure, the source and the history.

Skills

Stale device triage

Sorts devices that stopped checking in into replaced, lost and asleep, before anyone suggests retiring them.

  1. List devices with no check-in for the number of days asked, 30 if none.
  2. For each primary user, look for a sign-in from another device in the same period. If there is one, call the device replaced.
  3. Check the Autopilot profile before calling a device lost; kiosks have no primary user.

F. Recurring checks and the daily brief

The admin can ask for a read-only check to repeat, and for one brief per organization each morning. Each is confirmed on a card, listed per organization under the active one, and run only for the active organization while it is connected. A run that cannot happen is skipped and says why in the list; it is never caught up silently.
