Privacy

Control optional product telemetry and inspect the complete payload before anything is sent. Desktop telemetry is separate from website analytics and registry install counts.

Install and usage telemetry

Share coarse product counts and version classes to help prioritize compatibility and reliability work. This setting is off unless you enable it.

Off
Telemetry is off. No install or usage payloads are sent in the background.

Exact JSON payload preview

counts and versions only
{
  "anonymousId": "oao_7c91f4a2b8e6",
  "appVersion": "0.5.0",
  "platform": "win32",
  "providerClass": "local",
  "tenantCountBucket": "2-5",
  "agentCountBucket": "6-10",
  "runCountBucket": "51-100"
}

A test ping sends this preview once. It does not enable ongoing telemetry or change this switch.

Never included

The telemetry schema does not accept tenant or run content fields.

✓Tenant content and identityNo tenant names, tenant IDs, domains, users, devices, policies, or Microsoft Graph response data.
✓Prompts and model contextNo prompt text, workspace notes, cached evidence, provider credentials, or model inputs.
✓Results and run detailNo answers, findings, diffs, action plans, typed phrases, logs, errors, or exported files.
✓Exact activity countsTenant, agent, and run totals are converted to coarse buckets on this device before sending.

Field definitions

Every allowed field is visible here. Adding a field requires a product review and an updated payload preview.

FieldExamplePurpose
anonymousIdrandom local idDistinguish installations without an account or tenant identifier.
appVersion0.5.0Measure supported version adoption.
platformwin32Prioritize platform-specific compatibility work.
providerClasslocal | hostedUnderstand provider class usage without provider or model names.
*CountBucket0, 1, 2-5, 6-10, 11-50, 51-100, 101+Coarse tenant, installed agent, and retained run counts.
Tenant content, prompts, and results are never sent. Turning telemetry off stops future background payloads. The random anonymous ID can be reset from this page without deleting local OpenAdminOS data.
