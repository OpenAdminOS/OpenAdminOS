# Train assets for the Flap Hall training page

All files here are public domain / CC0 (no attribution required, commercial use
allowed). Sourced from FreeSVG.org, which publishes everything under Creative
Commons 0. Downloaded 2026-08-28.

| File | Source page | What it is |
|---|---|---|
| `train-emu-side.svg` | https://freesvg.org/train | Full side elevation of a modern multi-car EMU. 76 paths with discrete flat fills, so the livery recolors with a simple fill-map (e.g. to the Flap Hall amber/charcoal palette). Primary candidate for the line-map train. |
| `train-emu-flaphall.svg` | derived from `train-emu-side.svg` | The same EMU recolored to the Flap Hall tungsten palette and stripped of editor metadata. Inlined in `17-training-railway-concepts.html` (style 3). |
| `railroad-train-silhouette.svg` | https://freesvg.org/railroad-train-silhouette | Chunky steam locomotive silhouette with smoke, single fill. Good as a one-color amber silhouette. |
| `steam-locomotive-silhouette.svg` | https://freesvg.org/silhouette-vector-graphics-of-steam-locomotive | Taller, more detailed steam locomotive silhouette, single fill. |
| `train-station-silhouette.svg` | https://freesvg.org/train-station-silhouette | Ornate station facade silhouette (Vladivostok). Possible hall backdrop behind the split-flap board; the Cyrillic lettering would need removing. |

Evaluated and rejected: OpenGameArt "Animated train" and Wikimedia "Mogul
steam locomotive icon" (both CC-BY / CC-BY-SA, attribution required), Kenney
Train Kit and OpenGameArt "Locomotive" by 32kda (CC0 but 3D models, not 2D
side views).
