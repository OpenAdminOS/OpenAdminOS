# v0.4 copy inventory

This inventory records the stable wording changed by the v0.4 quality pass. It separates catalog copy from runtime values so trust, recovery, Settings search, and agent names do not drift between surfaces.

## Catalog-backed copy

| Area | Source | Consumers | Checks |
|---|---|---|---|
| Shared actions and statuses | `apps/desktop/src/copy/common.ts` | Modal, Chat, recovery actions | Non-empty and voice rules |
| Chat empty state and composer | `apps/desktop/src/copy/chat.ts` | Empty Chat, composer, Chat recovery | Banned phrases, punctuation, fixed examples |
| Agent outcomes and labels | `apps/desktop/src/copy/agents.ts` | Agent cards and suggestions | Shared display-name formatter |
| Recoverable errors | `apps/desktop/src/copy/errors.ts` | Chat failure and retry | Every error has what, optional why, and an action |
| Trust and data boundary | `apps/desktop/src/copy/trust.ts` | StatusStrip and hosted consent | Local/hosted derivation; no guessed region |
| Settings sections and rows | `apps/desktop/src/copy/settings.ts` | Settings navigation, search, Command Palette | Unique ids and shared search results |

The catalog tests live in `apps/desktop/src/copy/copy.test.ts`. Stable copy added by this pass is rejected when it is empty, uses hype language or emoji, ends with an exclamation mark, or uses three periods in place of an ellipsis.

## Derived and runtime copy

These values remain typed inputs rather than catalog literals:

- Tenant, workspace, provider, model, agent, and conversation names.
- Counts, timestamps, versions, Graph scopes, run ids, and resource ids.
- Specific host/provider failure details inserted into the optional error `why` field.
- Verified provider destination metadata. The trust derivation does not invent a region when the provider configuration has none.

`apps/desktop/src/shared/agent-display.ts` is the single formatter for agent names shown by Home, cards, Chat suggestions, Command Palette, and Run Result.

## Deliberately local labels

Short structural labels whose meaning depends on their component remain at the call site: tab names, field labels, dynamic table headers, and domain-specific values in older flows outside the v0.4 pass. They should move into the catalog only when another surface consumes them; extracting every literal would make the catalog harder to review without improving consistency.
