# GitBook Theme

GitBook appearance is configured in the GitBook site customization UI. The repo owns the intended settings so the public docs can be reproduced.

## Recommended Settings

| Setting | Value |
| --- | --- |
| Site title | OpenAdminOS |
| Theme | Clean or Muted |
| Default mode | Dark |
| Accent | Restrained blue or cyan |
| Corners | Small |
| Shadows | Minimal |
| Code theme | Dark |
| Logo | OpenAdminOS wordmark or app icon |

## Voice

Docs should use the same voice as the app: plain, specific, and slightly dry. Avoid hype language, exclamation marks, and vague error phrasing.

## Source Control Boundary

Markdown content and navigation live in this repository. Visual controls such as logo, accent color, and code theme live in GitBook site settings.
