To request removal of a logo, contact the maintainers through GitHub issues or the security contact in SECURITY.md.

OpenAdminOS shows each icon beside the service's name to identify the Microsoft 365 service it connects to. The icons are not covered by the MIT license of OpenAdminOS. Every file is used as Microsoft provides it: not redrawn, recoloured, cropped or combined with other marks. Microsoft provides one colour file for each, shown on light and dark surfaces alike.
