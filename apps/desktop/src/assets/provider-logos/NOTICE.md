# Provider logos

Product names and logos are trademarks or registered trademarks of their respective owners. OpenAdminOS is not affiliated with, endorsed by, or sponsored by any of them.

To request removal of a logo, contact the maintainers through GitHub issues or the security contact in SECURITY.md.

OpenAdminOS shows each logo beside the provider's name to identify the tool it connects to. The logos are not covered by the MIT license of OpenAdminOS. Every file is used as the owner provides it: not redrawn, recoloured, cropped or combined with other marks. Where the owner provides a variant for dark surfaces it is used there; otherwise the single official file is shown on both.
